你好,中国的朋友,这是制作音乐包的流程 <3

1. 准备歌曲.
   将 MP3, WAV, OGG, FLAC 或 M4A 文件直接放入 Input 文件夹.
   文件夹里的所有歌曲会制作成一个音乐包, 不读取子文件夹.
   也可以在工具里点击 Browse... 选择其他歌曲文件夹.

2. 添加封面 (可选).
   将 cover.png, cover.jpg 或 cover.jpeg 放在歌曲旁边.
   每个音乐包只放一张封面. 建议使用 512 x 512 或 1024 x 1024
   的正方形图片. 非正方形图片会从中心裁成正方形.
   工具会自动生成 512 x 512 的游戏贴图, 原图同时作为 mod 管理器
   的预览图片. 没有封面也可以正常生成和播放.

3. 双击 Music Pack Builder.exe.
   确认 Input folder 指向歌曲文件夹, 在 Pack name 中填写音乐包名称.
   这个名称会显示在游戏的轮盘中. 请使用英文, 数字, 空格或基本标点,
   不要使用中文或 Windows 文件名禁止的字符, 例如 /, \, :, *, ?,
   双引号, <, > 和 |.

4. 点击 Build Pack.
   等待生成完成, 工具会自动打开 Output 文件夹.
   成品文件名为 "音乐包名称.zip".
   歌曲会转换成单声道, 22,050 Hz, 16-bit PCM 音频,
   因此生成的 ZIP 可能比原来的压缩歌曲更大.

5. 安装或分享成品.
   将 Output 里的 ZIP 导入 mod 管理器, 与 Bingus Shared Loader
   和 Vehicle Radio Framework 一起启用.
   安装或替换音乐包后, 完全退出并重启游戏.
   每个音乐包占轮盘的一格, 按 addon 的实际加载顺序分配.
   选择该格后会随机播放包里的一首歌, 最多支持 12 个音乐包.

更新音乐包或制作另一个音乐包

更新已有音乐包: 修改歌曲或封面, 保持音乐包名称不变, 再点击 Build Pack.
Output 里同名的 ZIP 会被覆盖, 在 mod 管理器中替换旧版本即可.

移动或更新工具包时, 请保留 Tools/pack_ids.json, 它保存各音乐包的身份.
更改名称会创建另一个独立音乐包.
制作新音乐包时, 选择其他歌曲文件夹, 或替换 Input 中的歌曲,
再填写一个新名称并生成.

文件夹说明

Input: 放歌曲和可选封面.
Output: 存放生成的音乐包 ZIP.
Tools: 工具运行需要的文件, 请保持完整.

生成失败时, 可以查看 Tools/last_build.log.
不要在 ZIP 内运行 EXE, 也不要把 EXE 单独移出工具包!!!
